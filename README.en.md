## About

**Tchêventos** is a free, open-source tool for creating and organizing event schedules. It is designed for people who need a clear program, an overview of multiple activities, and schedules that are ready to consult or share—without making event planning more complicated.

Use it for university events, educational activities, private gatherings, company events, conferences, seminars, summits, or any occasion that needs an organized schedule.

The idea is simple: **make event planning easier and put a useful tool within everyone's reach**. Tchêventos is free for personal, educational, and professional use.

## Features

### Organize events your way

- **Custom event names.**
- **Flexible duration:** create schedules for one day or as many days as you need, including events that span different calendar years.
- **Automatic overview:** track the number of activities, total scheduled hours, and time overlaps.
- **Daily or full-schedule view:** see the activities and statistics for a single day, or the combined totals for the entire event.

### Find and explore activities

- **Quick search** by title, space, or notes.
- **Filters** by space/venue and category.
- **Table view:** organize the schedule and add or edit activities.
- **Matrix view:** explore the program as a horizontal timeline, with spaces as rows and times as columns. Existing activities can also be edited in this view.
- **Run of show:** consult the program alongside production information and notes.

### Customize each activity

Activities can include:

- Title, date, start time, and end time.
- Space, room, or track.
- Category and an individual accent color.
- Description and notes.
- Production notes.
- Speakers and participants, when applicable.

Accent colors use a palette familiar to users of Google tools, making activities easier to distinguish at a glance.

### Export, import, and share

- **CSV import and export:** save a schedule, share the file, or import it again to continue working. You can also keep separate files for different events.
- **Copy to Google Sheets:** copy the current schedule to your clipboard and paste it directly into a spreadsheet.
- **Export the matrix for Excel:** take the horizontal timeline into a spreadsheet.
- **Export an event program:** generate a neatly organized schedule that presents times and activities in the style of programs used at conferences and summits.
- **Start fresh:** clear the current activities when you need to create a new schedule.

### A comfortable interface

- A simple, dynamic, easy-to-use interface.
- Light and dark modes.
- Automatic browser saving, with no need to click a Save button.

## How your data is stored

Tchêventos automatically saves the current schedule in your browser's local storage. Your changes are saved as you work, without requiring manual saves.

**Please note:** locally stored data is not automatically synchronized across browsers, devices, or people. To back up a schedule, share it, or continue on another device, export it as a CSV file. You can then import that file to resume working. Clearing the site's browser data may delete the schedule stored locally.

## Development

Tchêventos is built with **React**, **TypeScript**, and **Vite**.

To run the project locally, install [Node.js](https://nodejs.org/) and npm. Then clone this repository and run:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with the actual repository owner and name.
